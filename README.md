# Windify
Браузерное расширение, которое добавляет BigusFackingBrainusa31 на превьюшечки видосов YouTube.

---

### Что делает расширение:
- Накладывает оверлей с лицом Андрея на превью видео на главной странице YouTube, в поиске и в других разделах.
- Добавляет фирменные приписки к названиям роликов: *(и это правда страшно...)*, *(тебе конец...)* и другие.
- **Меню настроек**: нажав на значок расширения в браузере, можно выключить лица, приписки или выбрать, какие именно фразы будут чередоваться.
- Не накладывает оверлей на ролики самого Винди31.
- Пропускает Shorts.
- Мгновенно скрывает его лицо, когда включается предпросмотр видео при наведении курсора.

## Установка на ПК (Chrome, Яндекс Браузер, Opera, Edge и т.д)

1. Скачайте архив `Windify-v1.1.0.zip` из раздела **Releases** (справа на этой странице).
2. Распакуйте скачанный архив в любую папку на компьютере.
3. Откройте страницу расширений в браузере:
   - В Google Chrome: перейдите по адресу `chrome://extensions/`
   - В Яндекс Браузере: `browser://extensions/`
   - В Opera: `opera://extensions/`
4. Включите переключатель **«Режим разработчика»** (в правом верхнем углу).
5. Нажмите кнопку **«Загрузить распакованное расширение»** и выберите папку с распакованными файлами.
6. Готово! Расширение установлено, вот так, не сложно вроде.

## Установка на Firefox (ПК)

1. Скачайте архив `Windify-v1.1.0.zip` из раздела **Releases**.
2. В адресной строке Firefox введите: `about:debugging`
3. Слева нажмите **«Этот Firefox»** (This Firefox).
4. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on) и выберите скачанный `.zip` архив (распаковывать не обязательно).
*(После одобрения в каталоге Mozilla Add-ons здесь появится ссылка на установку в один клик)*

## Установка на Safari (iPhone, iPad, Mac)

В Safari обычные расширения просто так не поставить, поэтому я сделал Юзерскрипт:

1. Установите бесплатную прогу **Userscripts** из App Store.
2. Зайдите в *Настройки ➔ Safari ➔ Расширения* и включите там **Userscripts** (дайте доступ, если спросят).
3. Откройте прямо в Safari ссылку на скрипт:  
[Установить скрипт windify.user.js](https://raw.githubusercontent.com/Rell10N/windyfy-extension/main/Safari/windify.user.js)
4. В адресной строке Safari нажмите на значок расширения ➔ выберите **Userscripts** ➔ нажмите **«Install»** (Установить).
5. Зайдите на YouTube через Safari. И всё должно работать.

## Установка на телефон (Android)

Стандартный Chrome на Android не поддерживает расширения, поэтому нужен браузер с их поддержкой (например, Kiwi\Lemur Browser).

1. Установите **Удобный ВАМ Browser** из Google Play.
2. Скачайте ZIP-архив из Releases и распакуйте его (или если не надо, не распаковывайте).
3. Откройте Browser и введите в адресную строку: `chrome://extensions/` либо зайдите по другому.
4. Включите переключатель **«Developer mode»** (Режим разработчика).
5. Нажмите кнопку **«+(.zip / .crx / .user.js)»** и выберите распакованную папку с расширением.
6. Либо для другого браузера, как то по другому, везде по разному, смотрите сами.
7. Готово! Расширение установлено.
